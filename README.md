# MCA Placement Management System – ER Model

## Description

This project presents the Entity-Relationship (ER) model for an MCA Placement Management System.

## Main Entities

- Student
- Department
- Academic Record
- Company
- Placement Drive
- Training
- Selection Process
- Test
- Student Selection
- Offer
- Report

## Purpose

The ER model represents the entities, attributes, relationships, and cardinalities required to manage students, companies, placement drives, selection processes, and placement offers.
